Formulary RxNorm Enrichment Tool

Instructions

This tool enriches your formulary.json with RxCUI and RxNorm concept names from the NLM RxNorm public API. Run it once on desktop Safari or Chrome.

1. Click Load formulary.json and select the file from your downloads or repo folder.
2. Click Start Enrichment — it will run for ~25-30 minutes.
3. When complete, click Download Enriched formulary.json and upload it to GitHub.

Safe to pause and resume — already-enriched formulations are skipped on reload.
